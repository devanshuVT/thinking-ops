# 0001. GitHub is the system of record

Date: 2026-10-15
Context: Agents, ideas and decisions were spread across chat, a hosted dashboard and scheduled tasks, with no history.
Options: (a) hosted dashboard database, (b) Notion-style tool, (c) a git repo with markdown files.
Choice: (c). One file per agent, idea, task and decision; commits are the audit trail; Actions regenerate BOARD.md.
Why: free versioning of thinking, works for Codex and Claude without extra tooling, diffs show how decisions changed.
What would change my mind: more than about 100 active items, or a need for real-time multi-user editing.
